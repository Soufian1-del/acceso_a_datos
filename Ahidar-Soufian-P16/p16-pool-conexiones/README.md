# P16 - Pool de conexiones

Proyecto base de la app de reparto de comida RepartoBarrio.

## Cómo ponerlo en marcha

1. Comprueba que el servicio de MariaDB está en marcha (`services.msc`).
2. Ejecuta `datos/init.sql` en DBeaver con Alt+X. Crea la base de datos `ad_p16`.
3. Cambia `TU_USUARIO` y `TU_CONTRASENA` en `src/main/resources/conexion.properties`.
4. Ejecuta `es.fplumara.dam.ad.p16.Principal`.
