# P14 · Transacciones · Venta de entradas para conciertos

Proyecto base de la práctica P14.

## Cómo arrancar

1. Comprueba que el servicio de MariaDB está en marcha (services.msc).
2. Abre `datos/init.sql` en DBeaver, conéctate a MariaDB y ejecútalo con Alt+X. Crea la base de datos `ad_p14`.
3. En `src/main/resources/conexion.properties`, cambia `TU_USUARIO` y `TU_CONTRASENA` por tu usuario y tu contraseña de MariaDB.
4. Ejecuta `es.fplumara.dam.ad.p14.Principal`.

Para volver a dejar los datos como al principio, ejecuta otra vez `datos/init.sql`.
