# P06 · Serialización de objetos

Proyecto base de la práctica P06 de Acceso a Datos (2.º DAM).

## Qué trae

- `modelo/Partida.java`, `modelo/Personaje.java` y `modelo/Objeto.java`: el modelo de una partida guardada de «Crónicas de Ébano».
- `util/DatosIniciales.java`: crea en memoria una partida de ejemplo (4 personajes y 20 objetos).
- `datos/`: carpeta vacía donde el programa guardará `partida.sav`.

## Cómo abrirlo

1. Descomprime el zip.
2. En IntelliJ IDEA: File > Open y elige la carpeta `p06-serializacion`.
3. Espera a que Maven termine de cargar el proyecto.
4. Sigue el enunciado a partir del Paso 1.

No necesita Docker ni dependencias externas: solo el JDK 25.
