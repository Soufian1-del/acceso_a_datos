# P12 · Consultas y objetos de resultado

Catálogo de videojuegos en MariaDB: las filas de cada consulta se convierten en objetos Java.

## Cómo arrancar

1. Comprueba que el servicio de MariaDB está en marcha (`services.msc`).
2. Ejecuta `datos/init.sql` entero en DBeaver con Alt+X. Crea la base de datos `ad_p12`.
3. Pon tu usuario y tu contraseña de MariaDB en `src/main/resources/conexion.properties`.
4. Ejecuta `es.fplumara.dam.ad.p12.Principal`.
