# P13 · Metadatos — App de recetas

Mini explorador de una base de datos MariaDB con `DatabaseMetaData` y `ResultSetMetaData`.

## Cómo arrancar

1. Comprueba que el servicio MariaDB está en ejecución (`services.msc`).
2. Ejecuta `datos/init.sql` entero en DBeaver con Alt+X. Crea la base de datos `ad_p13`.
3. Pon tu usuario y tu contraseña de MariaDB en `src/main/resources/conexion.properties`.
4. Ejecuta `es.fplumara.dam.ad.p13.Principal`.
